# کش‌بک و کیف پول ووکامرس

افزونه کش‌بک و کیف پول برای ووکامرس با رابط فارسی و مینیمال.

## ویژگی‌ها
- کش‌بک درصدی
- کش‌بک مبلغ ثابت
- ذخیره اعتبار در کیف پول
- استفاده از کیف پول فقط برای پرداخت خرید
- بدون برداشت به کارت بانکی
- تاریخچه تراکنش‌ها
- آماده اتصال ملی‌پیامک و فراز SMS
- رابط فارسی و مینیمال
