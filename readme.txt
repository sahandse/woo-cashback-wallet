== Description ==
Woo Cashback Wallet grants store credit after completed orders and keeps wallet balance available for future purchases.

== Installation ==
1. Upload the woo-cashback-wallet folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > کش‌بک و کیف پول.
